bivreg

Bivariate regression tables

Regression & Analysis

Installation

net install bivreg, from("https://raw.githubusercontent.com/bbdaniels/stata/main/")

Description

bivreg produces bivariate regression tables, useful for exploring relationships between variables without additional controls.
